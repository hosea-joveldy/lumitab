# Lumitab

Lumitab is a Firefox new-tab extension that is suitable for nix/nixos users, especially those who contribute to nixpkgs.

## Themes

<details>
<summary><strong>Solar</strong> — complete. An animated 3D solar system, clock, Google and NixOS package search, settings, and optional GitHub and nixpkgs stats.</summary>

<br>

![Solar theme screenshot](./assets/lumitab-solar.png)

</details>

<details>
<summary><strong>Glass</strong> — complete. A frosted-glass startpage with clock, multi-engine search, settings, quick dock, and optional GitHub and nixpkgs stats.</summary>

<br>

![Glass theme screenshot](./assets/lumitab-glass-with-bg.png)
![Glass theme screenshot with default glow](./assets/lumitab-glass-no-bg.png)

</details>

The theme implementations live in `solar/` and `glass/`.
