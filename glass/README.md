# Lumitab Glass

A lightweight Firefox new-tab extension with a frosted-glass aesthetic. It features a live clock, multi-engine search, a quick-access dock, customizable color themes and background, and GitHub contribution and nixpkgs pull request stats.

![Lumitab Glass with default glow theme](../assets/lumitab-glass-no-bg.png)
![Lumitab Glass with custom background](../assets/lumitab-glass-with-bg.png)

## Features

- Time and date with automatic city detection and custom timezone support
- Multi-engine search with quick switching between Google, DuckDuckGo, NixPkgs, GitHub, and Wikipedia
- Frosted-glass UI with translucent cards and smooth animations
- Quick-access bookmark dock for favorite links
- GitHub contribution count and 52-week activity heatmap (with optional personal access token support)
- Nixpkgs pull request tracker for open and merged PRs
- Theme switcher: Catppuccin Mocha, Nord, Gruvbox, and Everforest
- Customizable background: animated theme glow or custom wallpaper upload with dimming control
